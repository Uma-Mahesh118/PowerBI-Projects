# PowerBI- Projects

This repository showcases two interactive Power BI dashboards designed to analyze and present data effectively. Each dashboard focuses on specific use cases and provides insights using visuals, KPIs, and filters.

## Dashboards Overview

## 1. Furniture Sales Dashboard

- **Description**:  
  The Furniture Sales Dashboard provides insights into the sales performance of a furniture store for the years 2021-22. It includes metrics such as total revenue, margin, number of items sold, and customer behavior.
- **Features**:  
  - **KPIs**: Displays total revenue, total margin, and items sold.
  - **Visualizations**:
    - Monthly trends of items sold.
    - Regional sales distribution.
    - Sales and margins by salesperson and product.
  - **Filters**:
    - Date, customer, region, and product-based filtering.
  - **Goal Tracking**: Highlights achieved and target values for sales goals.
- **Purpose**:  
  Enables store managers and stakeholders to monitor sales performance, identify trends, and take actionable insights for improving revenue.

### 2. **Student Dashboard**
- **Description**:  
  The Student Dashboard tracks the academic performance of students, providing insights into their weekly scores, KPI trends, and total scores.
- **Features**:  
  - **KPIs**: Displays the number of students and their distribution across performance levels.
  - **Visualizations**:
    - Average scores per student.
    - Total scores over time.
    - Weekly score breakdowns with color-coded indicators for performance (e.g., green for good, red for poor).
  - **Filters**:
    - Year, month, and student-based filtering.
  - **Detailed Data Table**:
    - Shows individual student scores across multiple weeks for granular analysis.
- **Purpose**:  
  Helps educators monitor student progress, identify at-risk students, and adjust teaching strategies to improve performance.

## How to Use
1. Download the `.pbix` files for the dashboards.
2. Open them in Power BI Desktop.
3. Replace the sample data with your actual data (if applicable).
4. Explore the interactive features such as filters, slicers, and visuals.

---

## Requirements
- Power BI Desktop (latest version recommended)
- Sample data files (included in the repository or replace with your data)
